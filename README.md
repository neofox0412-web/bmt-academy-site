# BMT 모든학원 관리페이지

학생 명단, 출결, 학습기록, 수납, 학부모 보고서를 한곳에서 관리하는 공개 MVP입니다.

- 사이트: https://bmt-academy-admin-v2.vercel.app
- 배포: Vercel Drop to Deploy
- 데이터·로그인: Supabase Auth + PostgreSQL
- 접근 보호: 로그인 사용자 전용 RLS 정책
- 학생 등록: 이름, 학년, 반, 보호자 연락처, 학생 연락처, 생일, 등록일, 집주소, 수납, 점수, 최근 학습내용
- 샘플 데이터: 가명 학생 20명, 출결 20건, 학습기록 20건

처음에는 사이트에서 이메일과 비밀번호를 입력하고 **계정 만들기**를 누른 뒤 로그인합니다.
